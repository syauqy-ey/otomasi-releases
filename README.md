# Otomasi

Paket aplikasi Otomasi untuk Windows x86_64 dan Mac Apple Silicon. Source aplikasi disimpan pada repository private yang terpisah.

Rilis pertama sedang dipersiapkan. Unduhan akan tersedia di halaman Releases setelah paket kedua platform lolos pemeriksaan.

Setiap rilis menyediakan paket Windows, paket Mac, dan latest.json bertanda tangan untuk pemeriksaan pembaruan dari aplikasi. Input, output, pengaturan, password SSH, dan kunci penandatanganan privat tidak dipublikasikan.
